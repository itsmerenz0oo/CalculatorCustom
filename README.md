# Custom Calculator

A clean, responsive, and customizable calculator application designed to perform basic and advanced mathematical calculations seamlessly.

---

## 🚀 Features

*   **Standard Operations:** Addition, subtraction, multiplication, and division.
*   **Advanced Math Functions:** Support for powers, square roots, percentages, and parentheses.
*   **Keyboard Navigation:** Full support for physical keyboard inputs for fast calculations.
*   **Responsive UI:** Optimized layout across mobile, tablet, and desktop devices.
*   **History Log:** Tracks previous calculations for easy reference.
*   **Theme Switcher:** Toggle between light and dark visual themes.
